## Usage

```tsx
import { CommandTree } from "@/components/commandly/command-tree";
```

### Basic Usage

```tsx
const [selectedCommand, setSelectedCommand] = useState(() => getDefaultCommand(tool));

// The tree scrolls internally, so give it a bounded height.
<div className="h-96">
  <CommandTree
    tool={tool}
    selectedCommand={selectedCommand}
    onSelectCommand={setSelectedCommand}
  />
</div>;
```

## API Reference

### CommandTree

| Prop              | Type                                 | Default | Description                                            |
| ----------------- | ------------------------------------ | ------- | ------------------------------------------------------ |
| `tool`            | `Tool`                               | -       | The tool definition whose commands are listed          |
| `selectedCommand` | `Command \| null`                    | -       | The command to highlight; `null` highlights the root   |
| `onSelectCommand` | `(command: Command \| null) => void` | -       | Called with the chosen command, or `null` for the root |
| `className`       | `string`                             | -       | Additional classes for the tree container              |

## Notes

- The search box matches a command on the path it is invoked with, plus its description and aliases, so a nested command can be found without expanding its parents
- Each command row counts its own parameters; the root row counts the tool's own parameters and, in outline, the ones inherited through `recursive`
- Clicking anywhere on a branch row both selects that command and toggles its subtree; the chevron turns down while the subtree is open
- The tree fills the height its container gives it and scrolls its own command list, so a tool with hundreds of commands does not scroll the page
- An interactive command is marked with a keyboard icon
